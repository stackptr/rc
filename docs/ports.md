# Open ports

Generated by `scripts/ports` from the evaluated host configurations, and checked by CI: edit the Nix, then rerun it.

- **Internet**: spore's firewall (public IPv4 address; IPv6 is off), and the router's port forwards to home hosts.
- **LAN**: the home network. Each home host's global allow lists, plus its extra rules.
- **Tailnet**: tailscaled's `ts-input` chain, first in filter `INPUT`, accepts all traffic from `tailscale0`, so neither `trustedInterfaces` nor `tailscale0` allow lists filter it. Only a rule in an earlier table (mangle) does.

An allowed port with nothing listening on it is closed: this lists what the firewall lets through, not what's running.
